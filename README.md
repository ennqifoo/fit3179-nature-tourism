# FIT3179 DV2: Nature-based tourism in Australia

Single-page Vega-Lite visualisation of nature tourism in Australia. Specs are in `specs/`, data in `data/`.

## Data sources
- Tourism Research Australia: National Visitor Survey, Domestic Tourism Statistics, International Visitor Survey
- Australian Bureau of Statistics: ASGS boundaries (CC BY 4.0)

## AI use
I used Claude (Anthropic) to help plan the story, write the data-wrangling scripts and Vega-Lite specifications, and draft the text. I checked the numbers against the sources above and edited the result. All data come from the cited sources; no data were generated by AI.
## Contents
- `index.html`, `css/style.css`, `js/main.js`: the single web page
- `specs/`: one readable Vega-Lite JSON file per chart (14 charts)
- `data/`: small CSV and TopoJSON files (about 0.6 MB in total)
- `sketch/`: A4 sketch (PDF)

## Data processing
Index values (2019 = 100), spend per trip (spend divided by trips), state ranks and quarterly seasonality indices were calculated from the published tables. Dots on the dot map are placed at random inside each region (1 dot = 100,000 trips). The cartogram and treemap layouts were computed and saved as CSV.
